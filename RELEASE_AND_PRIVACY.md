# Private Archive and Sharing Rules

## Intended audience

This repository is a private, complete view of the current experiment for professor review.

It is not a sanitized public-data release.

## Included private research material

The archive intentionally includes:

- all frozen prompts;
- all 96 verbatim consumer-product responses;
- complete capture metadata;
- reviewer packets;
- preserved original human-rating exports;
- adjudication materials;
- the administrative blinding key;
- product-blinded and unblinded row-level datasets;
- analysis outputs and tables;
- freeze and integrity receipts;
- the technical report; and
- the one-page professor brief.

## Access rule

Only people intentionally invited to the private GitHub repository should have access.

GitHub does not provide folder-level privacy inside one repository. Every collaborator with repository access can read every tracked file, including raw ratings and administrative mappings.

## Do not make public without a separate review

Before any public release, review:

- reviewer consent and identity fields;
- adjudicator identity fields;
- free-text reviewer rationales and timestamps;
- administrative response-to-product mappings;
- verbatim consumer-product output redistribution terms;
- public operational contact details reproduced inside responses;
- local machine paths and private project identifiers;
- the intended public license.

A public release should be produced as a separate allowlisted export. It should not be created by simply changing this repository from private to public.

## Credentials scan

The 1 September 2026 pre-push review found no obvious API key, password, bearer token, private key, `.env` file, or personal credential. The scan covered the repository's text files and the text members of its ZIP/DOCX archives. Repeat a dedicated secret scan before any later public export.

One retained file contains a local machine path with the account directory name: the frozen final-report receipt's historical build path. This is a documented provenance detail, not a credential, and remains in this complete private archive.

## No public license

This private archive does not grant permission for public reuse or redistribution. A license decision belongs to a future public-release process.
